# IMU Brick Breaker

라즈베리파이에서 ESP32 IMU 입력으로 테스트하는 스마트글래스용 게임 프로토타입입니다.

## 게임 개요

- `index.html`
  - IMU 기반 벽돌깨기 게임
  - 양팔을 동시에 들어 올리면 시작 / 다음 레벨 / 재시작
  - 왼팔을 들면 왼쪽 패널 활성화
  - 오른팔을 들면 오른쪽 패널 활성화
  - 양팔을 들면 가운데 패널 활성화
  - 3개 레벨 구성

## 레벨 구성

- 레벨 1
  - 벽돌 수 적음
  - 공 속도 느림
- 레벨 2
  - 벽돌 수 증가
  - 공 속도 증가
- 레벨 3
  - 가장 많은 벽돌
  - 가장 빠른 공 속도

## 센서 입력 규칙

- `IMU1`: 왼팔
- `IMU2`: 오른팔
- `IMU3`: 몸통

페이지가 처음 열리면 잠깐 baseline을 수집합니다.
이때 시작 자세를 유지하면, 이후 현재 IMU 변화량을 기준으로 팔 올림 동작을 판별합니다.

## 실행 방법

### 1. 브리지 실행

```bash
cd device/raspberry-pi
python3 pi_sensor_bridge.py \
  --serial-port /dev/ttyUSB0 \
  --ws-host 0.0.0.0 \
  --ws-port 8765 \
  --ui-host 0.0.0.0 \
  --ui-port 8080
```

### 2. 게임 페이지 실행

```bash
cd device/raspberry-pi/game
python3 -m http.server 8090
```

브라우저 또는 스마트글래스에서:

```text
http://<raspberry-pi-ip>:8090
```

## 권장 테스트 순서

1. ESP32 센서 프레임이 `sensor_frame`으로 들어오는지 확인
2. 게임 페이지를 열고 baseline이 끝날 때까지 가만히 있기
3. 양팔을 동시에 들어 올려 게임 시작
4. 왼팔 / 오른팔 / 양팔 입력에 따라 좌/우/가운데 패널 활성화 확인
5. 레벨 클리어 후 다시 양팔을 들어 다음 레벨 진입 확인
